# UPTET Saathi

Offline-first, bilingual (Hindi/English) revision app for UPTET and CTET candidates. Flutter + sqflite, Android only.
Goal for the pilot: run free apart from the Google Play developer account, so no backend or paid services.

## Commands

```
flutter test                                  # all tests (sqflite_common_ffi, no device needed)
flutter analyze
dart run tool/validate_content.dart           # validate assets/content/content_pack.json
flutter build apk --release                   # build/app/outputs/flutter-apk/app-release.apk
```

Run all three checks after any change to the content pack or the content model.

## Layout

- `lib/models/content.dart`: content pack model (subjects, topics, questions, papers) and JSON parsing.
- `lib/models/content_index.dart`: lookups over the installed pack (`papersFor(exam, level)`, paper languages).
- `lib/database/app_database.dart`: schema as a list of append-only migrations. Never edit a shipped
  migration; add a new entry. `test/database/app_database_test.dart` upgrades v1 to current.
- `lib/repositories/`: SQLite access. `content_repository.dart` installs the bundled pack.
- `lib/services/content_validator.dart`: pack checks. Release rules are errors only when
  `release_ready` is true, otherwise warnings.
- `lib/services/scoring.dart`, `revision_scheduler.dart`, `progress_calculator.dart`: tunables live in `lib/config.dart`.
- `lib/l10n/strings.dart`: all UI strings, in both languages.
- `tool/pyq/`: Python scripts that import previous papers from PDFs (see its README).

## Content rules

- `assets/content/content_pack.json` is generated by `tool/pyq/build_uptet.py` and
  `build_ctet_feb26_p1s.py`. Fix UPTET content in the section modules (`tool/pyq/u18|u19|u21`)
  and rebuild, not by hand in the JSON, or the next rebuild loses the fix.
- Official papers need `exam` (uptet/ctet) and `level` (primary/junior). A paper lists its own
  `question_ids`, so Junior papers share their common parts.
- Subjects with `language` (hin, eng) hold questions in that language only.
- Explanations are our own writing. Answers follow the source key; skip questions whose answer is
  wrong or ambiguous or that need a figure, and note disputed answers in the explanation.
- Every imported question stays `verification_status: pending_review` until checked against the
  official booklet and final key.

## Before going live

- `distribution_cleared` and `release_ready` stay false until written permission arrives from
  the rights holders: CBSE for CTET, and Pariksha Niyamak Pradhikari UP, Prayagraj
  (updeled.gov.in) for UPTET. examregulatoryauthorityup.in is not an official site.
- Release signing still uses the debug key (`android/app/build.gradle.kts`).

## Conventions

- Match the existing style: short doc comments that explain why, no comment noise.
- User-facing text goes through `strings.dart` in both Hindi and English.
- Git: commit only when asked. No Claude co-author or attribution lines in commits.
